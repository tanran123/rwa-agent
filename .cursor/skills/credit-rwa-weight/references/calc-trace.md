# 计算留痕

文件：`agent/subagents/weight/calc/calc_trace.py`。留痕写在仓库根目录 `output/traces/`。`save_trace_file` 在那里写两份文件，文件名是工作簿主文件名加 `-计算留痕`。主文件名里除字母、数字、中文、点、连字符以外的字符换成下划线。

## 一行里的步骤

`agent/subagents/weight/calc/paper_calc.py` 的 `_calculate_sheet` 为每一笔先放事实，再放分类，再放敞口和风险加权资产。

1. 阶段「取值」：事实里不以 `_` 开头、且不是空的每一项各一步。`field` 和 `actual` 都是该字段的值。
2. 阶段「分类」：`condition_steps` 把走到的每个节点的 `all` / `any` 摊平。每条条件一步，带规则名、字段、比较、规则值、实际值、是否命中。节点没有条件时写一步说明：要么是同层其余都未命中所以落入这一档，要么是进入这一档。
3. 阶段「权重」：最后一档的规则名和显示用的权重。权重不是数字时，说明是「这一档没有固定权重」。`same_as` 或 `greater_of` 再走的普通债权，步骤照样附上，说明里加「按交易对手的普通债权再走一次」。
4. 阶段「敞口」：这一行用于计算的金额。
5. 阶段「风险加权资产」：权重是数字时结果是金额乘权重；否则这一步不命中，说明「权重未定，不计入」。

`number_steps` 从 1 给这些步骤编号。比较符在写出前换成中文：等于、不等于、属于、包含、大于、大于等于、小于、小于等于。

## JSON

```json
{
  "file": "工作簿名.xlsx",
  "saved_at": "计算时间",
  "rows": [
    {
      "sheet": "源表",
      "excel_row": 14,
      "name": "客户或编号",
      "exposure": "大类 · 细类",
      "weight": "20%",
      "ead": 180735000,
      "rwa": 36147000,
      "steps": [],
      "formula": {
        "expression": "风险加权资产 = 敞口 × 权重",
        "substituted": "180735000 × 20% = 36147000"
      }
    }
  ]
}
```

`weight` 优先用已经写成百分比的 `weight_text`。权重未定时代入句是「敞口 …，权重未定，不计算风险加权资产」。没有敞口时是「这一行没有敞口，不计算风险加权资产」。`ead`、`rwa` 与源表金额同一单位。

## Markdown 和 Excel

`render_trace_markdown` 按行写：风险暴露、权重、公式、代入、流向、经历、取值、规则、权重。流向是 Mermaid，只画这一行实际走进的规则，不补没走到的分支。解释某一笔时只引用这一节。

Excel「计算留痕」表的列是：来源表、源表行、名称、序号、阶段、步骤、规则、字段、比较、规则值、实际值、命中、结果、说明。同一笔占多行，一行对应一个步骤。

判定说明（明细表末尾那一列，以及「风险暴露分类」的判定说明）不是完整步骤。它是命中路径用箭头拼起来，最多再加 80 字模型原因，整段截到 180 字。倒查规则名和公式以留痕 JSON 或 Markdown 为准。
