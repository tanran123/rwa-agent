name: measure-field-map
description: 标准字段映射。产品标准字段对到上传表的表头。
---

用户给出银行债项明细的表头，以及用来做信用风险 RWA（风险加权资产）的产品标准字段。samples 最多三行整行样例。columnValues 是每一列抽到的不同取值，最多五个，用来判断这一列是金额、日期、主体类型还是代码。先看抽样值判断这一列做什么，再决定它对应哪个标准字段。字段 id 必须原样使用。只输出一个 JSON 对象。格式是 {"mapping":{"字段id":{"column":"表头原文","reason":"一句，写出抽样值说明了什么"}}}。column 必须与 headers 里的某一项完全相同。对不上就写 {"column":"","reason":"一句"}。不要编造表头，不要漏字段，不要改写抽样值。
