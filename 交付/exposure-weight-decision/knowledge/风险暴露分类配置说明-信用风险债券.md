# 权重法风险暴露分类 JSON 编写指引（债券与同业专项更新）

分类规则位于 `knowledge/权重法风险暴露分类.json`。键为英文，界面显示的中文对应 `label`。

本次更新重点覆盖 AMCM 信用风险权重法下的债券、银行同业债权、主权债权、公共部门实体债权、多边开发银行债权及相关信用风险缓释规则。

**核心原则：债券不能统一使用一个固定风险权重，必须先识别发行主体，再根据发行人类别、外部信用评级、债项评级、受偿顺位及相关例外规则确定适用权重。**

---

## 一、分类规则的基本结构

| 键 | 作用 |
|---|---|
| `fields` | 分类所需字段，包括发行主体、债权类型、外部评级、评级类型、债项受偿顺位、原始期限、币种、融资来源、准备金及信用风险缓释信息。 |
| `rules` | 风险权重决策树。从上到下依次判断，命中后进入对应的 `children`；未命中时按 `otherwise` 处理。 |
| `extensions` | 在既有分类规则下增加更细的业务分类，不应改变监管规定的基本分类顺序及风险权重。 |
| `excel` | Excel 字段映射，将表头和单元格原文映射到字段 `name` 和对应的 `code`。 |
| `remark` | 给规则维护人员看的说明，不直接参与计算。 |

### 1.1 分类顺序

债券及同业债权按照以下顺序识别：

1. 确认金融工具属于债权、债券还是其他类型的风险暴露。
2. 确认债券发行人或债权交易对手的类别。
3. 判断是否属于主权、中央银行、公共部门实体、多边开发银行、银行或公司。
4. 判断是否存在合资格的外部信用评级。
5. 区分短期特定债项评级、长期特定债项评级和发行人评级。
6. 根据适用评级规则及受偿顺位确定信用质量等级。
7. 按相应主体类别的风险权重表确定初始风险权重。
8. 检查未评级债权例外、主权风险权重底线及其他适用限制。
9. 扣除特定准备金，处理符合条件的信用风险缓释。
10. 计算最终信用风险加权资产。

**不得仅凭债券名称、币种、市场类别或政府背景直接确定风险权重。**

## 二、字段定义与数据要求

字段的 `name` 使用英文，`label` 使用中文。规则条件中的 `field` 必须引用字段的 `name`。

### 2.1 债券及发行主体字段

| 字段 name | 中文名称 | 含义 |
|---|---|---|
| `instrument_type` | 金融工具类型 | 区分债券、普通债权及其他金融工具。 |
| `counterparty_type` | 发行人或交易对手类别 | 区分主权、中央银行、公共部门实体、多边开发银行、商业银行、公司等。 |
| `counterparty_name` | 发行人名称 | 用于核对发行主体及符合条件的多边开发银行名单。 |
| `issuer_jurisdiction` | 发行人所属司法管辖区 | 用于确定发行人注册地或所属主权。 |
| `issuer_rating` | 发行人外部评级 | 发行人层面的外部信用评级。不得自动等同于特定债项评级。 |
| `issue_rating` | 特定债项外部评级 | 对具体债券或债项作出的评级。存在合资格的特定债项评级时，原则上优先使用。 |
| `rating_agency` | 评级机构 | 记录评级所属的外部信用评估机构。 |
| `rating_type` | 评级类型 | 区分短期特定债项评级、长期特定债项评级和发行人评级。 |
| `credit_quality_grade` | 信用质量等级 | 根据适用评级映射确定的信用质量等级。 |
| `issue_seniority` | 债项受偿顺位 | 记录债项属于优先、同顺位或次级等类别。 |
| `reference_issue_rating` | 参考债项评级 | 在本债项没有评级时，记录用于推导风险权重的其他债项评级。 |
| `reference_issue_seniority` | 参考债项受偿顺位 | 用于判断参考债项评级能否适用于当前未评级债项。 |
| `original_maturity_months` | 原始合同期限 | 以月为单位，判断银行债权是否符合原始期限不超过三个月的优惠权重条件。 |
| `currency` | 债权计价币种 | 用于判断主权及中央银行债权是否适用本币计价规则。 |
| `funding_source` | 融资来源 | 用于判断相关主权或中央银行债权是否满足本币融资条件。 |
| `specific_provision` | 特定准备金 | 从账面本金（含应计利息）中扣除的特定准备金额。 |
| `principal_including_interest` | 含应计利息的本金金额 | 用于计算扣除特定准备金后的风险暴露金额。 |
| `has_collateral` | 是否有抵押品 | 判断债权是否存在符合监管要求的抵押品。 |
| `has_guarantee` | 是否有保证 | 判断债权是否存在符合监管要求的保证。 |
| `collateral_type` | 抵押品类型 | 识别现金存款、主权证券、公共部门实体证券及其他抵押品。 |
| `guarantor_type` | 保证人类别 | 用于确定保证覆盖部分适用的保证人风险权重。 |
| `same_currency_collateral` | 抵押品与债权是否同币种 | 用于检查特定抵押品例外的币种条件。 |
| `specific_rating_reflects_guarantee` | 债项评级是否已反映保证 | 防止对已在债项评级中反映的信用增级重复确认 CRM 效果。 |

### 2.2 字段填写原则

1. `issue_rating` 和 `issuer_rating` 必须分别记录，不得混为同一评级。
2. 评级机构应限定为 AMCM PDF 第 12 段列明的合资格外部信用评估机构：S&P、Moody's、Fitch 和 R&I。
3. 应记录评级来源、评级类型、评级等级及对应债项的受偿顺位。
4. 不能确认评级是否有效、是否属于主动评级或是否符合监管认可条件时，应将状态标记为待核实，不得直接采用较低风险权重。
5. 不能确认发行主体类别时，不得仅根据发行人名称推定为主权、公共部门实体或多边开发银行。
6. 对于缺少必要评级、币种、期限或受偿顺位信息的债权，应输出信息不足及待补充字段，不得擅自假设。

## 三、外部评级的通用规则

### 3.1 合资格外部信用评估机构

仅使用 AMCM PDF 第 12 段列明的合资格外部信用评估机构的主动评级：

- S&P
- Moody's
- Fitch
- R&I

不得自行加入其他评级机构，也不得在没有监管依据的情况下，将未经认可的评级转换为信用质量等级。

### 3.2 多个评级的处理

必须遵守禁止 Cherry-picking 的规则，不得只选择风险权重最低的评级。

**同一债权有两个评级时：**

如果两个评级对应不同风险权重，采用其中较高的风险权重。

**同一债权有三个或以上评级时：**

1. 确定所有评级分别对应的风险权重。
2. 选出对应两个最低风险权重的评级。
3. 在这两个评级中采用较高的风险权重。

不得直接选取所有评级中最低的风险权重。

### 3.3 特定债项评级与发行人评级

应按照以下顺序判断：

1. 如果存在适用的特定债项评级，原则上使用该评级。
2. 如果债项没有评级，检查是否存在可用于推导风险权重的同一发行人其他债项评级。
3. 只有当未评级债权的受偿顺位不低于参考评级债权，即同顺位或优先（pari passu or senior），才可以按照 PDF 第 16 段的适用条件使用参考评级。
4. 使用发行人评级时，同样必须满足相关监管条件及受偿顺位要求。
5. 不得使用短期评级支持未评级的长期风险暴露。

如果受偿顺位不满足要求，或者缺乏足够证据判断受偿顺位，应停止自动推导并标记为待核实。

## 四、主权及中央银行债权

对应 AMCM PDF 表 3。

### 4.1 澳门特别行政区政府及 AMCM 债权

以澳门币计价，并由澳门特别行政区政府或 AMCM 提供资金的债权，风险权重为 **0%**。

分类时必须同时检查币种及融资来源，不得仅因发行主体与澳门有关就直接认定为 0%。

### 4.2 其他中央政府及中央银行的本币债权

其他中央政府或中央银行以其所属司法管辖区本币计价并以该币种融资的债权，可以按照该司法管辖区当地监管规定的风险权重处理。

如果无法确认计价币种、融资币种或当地监管规定，不得直接适用本币计价豁免。

### 4.3 其他主权债权的风险权重

| 信用质量等级 | 风险权重 |
|---|---:|
| 1 | 0% |
| 2 | 20% |
| 3 | 50% |
| 4 | 100% |
| 5 | 100% |
| 6 | 150% |
| 未评级 | 100% |

### 4.4 分类要求

- 先识别是否属于主权或中央银行债权。
- 再检查是否满足澳门特别行政区政府或 AMCM 的特定条件。
- 再检查是否满足其他司法管辖区的本币计价及融资条件。
- 对不适用上述例外的债权，根据适用评级确定信用质量等级并查询表 3。
- 未评级主权债权按表 3 的未评级档处理，但应先检查是否存在适用的特别规则。

## 五、公共部门实体（PSE）债权

对应 AMCM PDF 第 31 段。

### 5.1 分类原则

公共部门实体债权通常采用比该 PSE 注册地所属主权债权高一档的风险权重。

但必须先确认发行主体确实属于监管意义上的公共部门实体。不得仅凭政府持股、政府背景、政府控制或名称中含有政府相关字样，就直接归入 PSE。

### 5.2 特殊风险权重规则

| 所属主权的信用质量等级 | PSE 风险权重 |
|---|---:|
| 4 或 5 | 100% |
| 6 | 150% |
| 未评级 | 100% |

对于不属于上述特殊情形的 PSE，按照 PDF 第 31 段规定的通常规则，结合其注册地所属主权的评级及适用风险权重确定结果。

### 5.3 分类要求

1. 确认交易对手属于 PSE。
2. 确认 PSE 的注册地或所属主权。
3. 获取该主权的信用质量等级。
4. 先检查第 31 段列明的特殊情形。
5. 不属于特殊情形时，按通常规则确定风险权重。

如果无法确认 PSE 身份或所属主权，不得自动采用 PSE 风险权重。

### 7.4 未评级银行债权的特殊规则

对于未评级银行债权，必须进一步检查以下条件。

**情形一：参考债权的短期评级对应 50% 或 100% 风险权重。**

未评级短期债权采用以下两项中的较高者：

- 100%；
- 按 PDF 第 16 段的评级推导规则确定的风险权重。

**情形二：参考债权的短期评级对应 150% 风险权重。**

该银行所有未评级债权均采用 150% 风险权重。

**情形三：主权风险权重底线。**

未评级银行债权的风险权重不得低于其注册地所属主权的风险权重。

### 7.5 银行债券分类流程

1. 确认发行主体为银行。
2. 判断是否存在适用的短期特定债项评级。
3. 如果存在，按照表 6 判断是否适用短期评级规则。
4. 如果不适用表 6，检查原始合同期限是否不超过三个月，以及是否存在预期展期。
5. 满足原始期限条件的，按表 7 处理。
6. 其他银行债权按表 8 处理。
7. 对未评级债权检查参考评级、未评级例外及主权风险权重底线。
8. 最终确认适用风险权重。

不得将剩余期限不超过三个月直接等同于原始期限不超过三个月。

## 九、表内债券的风险暴露金额与 CRWA 计算

对应 AMCM PDF 第 24—27 段。

### 9.1 基本公式

表内债券的信用风险加权资产计算公式为：

**CRWA = 扣除特定准备金后的本金金额 × 适用风险权重**

其中：

**扣除特定准备金后的本金金额 = 账面本金（含应计利息）－特定准备金**

风险权重以小数形式参与计算：

| 风险权重 | 计算值 |
|---|---:|
| 0% | 0 |
| 20% | 0.2 |
| 50% | 0.5 |
| 100% | 1.0 |
| 150% | 1.5 |

### 9.2 计算示例

假设某公司债券的账面本金（含应计利息）为 10,000,000，特定准备金为 100,000，适用风险权重为 100%。

扣除特定准备金后的本金金额：

10,000,000 − 100,000 = 9,900,000

信用风险加权资产：

9,900,000 × 100% = 9,900,000

该示例仅用于说明计算方法，实际权重应由发行人类别、评级和适用的监管规则确定。

### 9.3 计算要求

1. 必须先确定风险暴露金额，再乘以风险权重。
2. 特定准备金应从账面本金（含应计利息）中扣除。
3. 不得直接使用未扣除特定准备金的金额计算 CRWA。
4. 不得把风险权重百分比误当作风险暴露金额的扣减比例。
5. 对缺少本金、应计利息或特定准备金数据的记录，应标记信息不足。

## 十、信用风险缓释（CRM）

对应 AMCM PDF 第 24—27 段及第 82 段的相关规定。

### 10.1 基本原则

如果债券存在符合监管要求的抵押或保证，必须将受保护部分和未受保护部分分别计算。

**受保护部分：**

根据符合要求的抵押品或保证人的适用风险权重进行处理。

**未受保护部分：**

按照原交易对手或债券发行人的适用风险权重处理。

不得将整笔债券直接按照抵押品或保证人的风险权重计算，除非适用规则明确允许如此处理。

### 10.2 拆分计算公式

设：

- `E`：扣除特定准备金后的债券风险暴露金额；
- `E_protected`：符合要求的受保护部分；
- `E_unprotected`：未受保护部分；
- `RW_protected`：受保护部分适用的风险权重；
- `RW_unprotected`：未受保护部分适用的风险权重。

则：

`E = E_protected + E_unprotected`

`CRWA = E_protected × RW_protected + E_unprotected × RW_unprotected`

### 10.3 抵押部分的 20% 风险权重下限

除非符合 PDF 第 82 段列明的特定例外，否则抵押部分的风险权重下限为 20%。

相关例外包括：

- 现金存款；
- 按 20% 折价处理且与债权同币种的主权或公共部门实体证券。

具体是否满足例外条件，必须依据监管原文逐项核对，不得仅凭抵押品名称直接免除 20% 风险权重下限。

### 10.4 保证的处理

如果保证符合相关信用风险缓释要求，受保护部分按照适用的保证人风险权重进行处理。

必须核实：

1. 保证人身份及类别；
2. 保证是否符合适用监管要求；
3. 保证覆盖的风险暴露金额；
4. 保证覆盖范围及相关限制；
5. 受保护部分与未受保护部分的拆分依据。

### 10.5 禁止重复确认信用风险缓释

如果债券的特定债项评级已经反映了保证或其他信用增级，不得再次确认相同保证的 CRM 缓释效果。

系统应检查 `specific_rating_reflects_guarantee` 字段：

- `yes`：不得对已反映在特定债项评级中的相同信用增级重复确认 CRM。
- `no`：仍须检查相关抵押或保证是否符合 CRM 适用条件。
- `unknown`：标记为待核实，不得自动重复计算缓释效果。

## 十一、JSON 规则的编写方法

### 11.1 风险权重字段

`value` 表示已经确定的风险权重。

例如：

- 20% 写成 `0.2`；
- 50% 写成 `0.5`；
- 100% 写成 `1.0`；
- 150% 写成 `1.5`。

如果一条规则需要继续按照评级、原始期限或其他条件分档，应使用 `children`，不应在尚未完成分类时提前写入固定 `value`。

### 11.2 条件字段

标准条件格式：

```json
{
  "field": "counterparty_type",
  "op": "eq",
  "match": "commercial_bank"
}
```

其中：

- `field`：字段的英文 `name`；
- `op`：判断操作；
- `match`：用于比较的值。

常用 `op` 包括：

| op | 含义 |
|---|---|
| `eq` | 等于 |
| `in` | 属于指定集合 |
| `contains` | 多选字段中包含指定值 |
| `gt` | 大于 |
| `gte` | 大于或等于 |
| `lt` | 小于 |
| `lte` | 小于或等于 |

### 11.3 多条件规则

例如，判断是否属于原始期限不超过三个月的银行债权：

```json
{
  "name": "bank_short_original_maturity",
  "label": "原始期限不超过三个月的银行债权",
  "when": {
    "all": [
      {
        "field": "counterparty_type",
        "op": "eq",
        "match": "commercial_bank"
      },
      {
        "field": "original_maturity_months",
        "op": "lte",
        "match": 3
      }
    ]
  },
  "children": []
}
```

**注意：上述示例仅展示字段及条件的编写方法，不代表已完整实现表 7 的所有监管条件。** 实际规则还必须检查是否存在预期展期、适用的评级分类及相关例外。

## 十二、Excel 字段映射规则

大模型负责将 Excel 表头及数据映射到 JSON 中已经定义的字段，不应擅自修改监管风险权重表。

### 12.1 映射原则

1. 读取字段的 `label`、`meaning`、`source` 和 `options`。
2. 根据 Excel 表头及样例数据匹配字段。
3. 将匹配结果写入 `excel`。
4. 不得因为 Excel 中某个字段缺失，就自行修改 `rules` 中的监管条件。
5. 无法确认的字段应保留未映射状态，不能根据字段名称猜测并自动填写。

### 12.2 枚举映射示例

```json
{
  "field": "counterparty_type",
  "columns": ["发行人类别"],
  "values": {
    "商业银行": "commercial_bank",
    "一般企业": "corporate",
    "主权政府": "foreign_sovereign",
    "公共部门实体": "pse",
    "多边开发银行": "mdb"
  }
}
```

`values` 中的值必须与 JSON 字段 `options` 中的 `code` 一致。

如果 Excel 中的发行人分类不明确，应标记为待核实，而不是强行映射。

### 12.3 数字字段映射

对于金额、期限和比例字段：

- 金额应统一使用约定的货币单位；
- 原始期限应统一为月；
- 风险权重应使用小数表示；
- 比例应使用比值表示，例如 20% 写成 `0.2`；
- 如果原始 Excel 中的百分比为 `20`，应在映射转换中除以 100。

## 十三、异常及待核实情形

以下情况不得直接输出确定的最终风险权重：

1. 发行主体类别无法确认。
2. 评级机构不属于合资格 ECAI。
3. 无法确认评级是否为主动评级。
4. 多个评级未按监管规则处理。
5. 将发行人评级错误地当作特定债项评级。
6. 未评级债权的参考评级不满足受偿顺位条件。
7. 使用短期评级推导未评级的长期风险暴露。
8. 银行债权原始期限或展期情况不明确。
9. 未评级银行或公司债权的特殊规则尚未检查。
10. 未评级债权的主权风险权重底线尚未检查。
11. 公共部门实体资格无法确认。
12. 多边开发银行是否属于明确的 0% 名单无法确认。
13. 特定准备金数据缺失。
14. 抵押或保证的覆盖金额无法确认。
15. 抵押品是否满足 20% 风险权重下限例外的条件不明确。
16. 债项评级是否已经反映保证等信用增级尚不明确。
17. 相关监管规则未覆盖当前交易结构。

对于上述情况，系统应输出缺失信息、适用规则、待核实事项及所需补充材料。不得通过自行假设或选择较低权重来填补信息缺口。

## 十四、监管依据与维护原则

本文件所列风险权重及规则对应用户提供的 AMCM PDF 内容摘要，主要涉及：

- 第 12 段：合资格外部信用评估机构；
- 第 16 段：未评级债权的评级推导规则；
- 第 24—27 段：风险暴露金额、准备金及信用风险缓释相关处理；
- 第 31 段：公共部门实体债权；
- 第 32 段：符合条件的多边开发银行及国际组织；
- 第 82 段：特定抵押品风险权重下限例外；
- 表 3：主权及中央银行债权；
- 表 5：其他多边开发银行及国际组织；
- 表 6：有短期特定债项评级的银行债权；
- 表 7：原始期限不超过三个月的其他银行债权；
- 表 8：一般银行债权；
- 表 9：有短期特定债项评级的公司债权；
- 表 10：其他公司债权。

### 维护要求

1. 修改风险权重时，应记录对应的监管段落或表格。
2. 新增发行人类别时，应先确认监管文件是否提供相应分类及权重规则。
3. 新增评级机构时，必须有监管依据。
4. 新增合资格多边开发银行时，必须核实适用名单及监管条件。
5. 不得仅为匹配业务数据而修改监管风险权重。
6. 不得把未评级、缺失信息或待核实状态直接转换为最低风险权重。
7. 如果监管原文与本文件的概括不一致，应以适用的正式监管文件为准，并修订本文件。

**最终原则：先识别债权及发行人类别，再处理评级与受偿顺位，然后匹配风险权重表，最后检查例外、准备金和信用风险缓释。所有自动计算结果均应保留对应的监管依据及判断过程。**
