# 市场风险报表 - 债券业务填报规则（基于第44页及之后内容）

## 一、适用范围与定义

### 1. 交易账簿（Trading Book）定义
- 交易账簿包括以交易意图持有的金融工具及商品头寸，或用于对冲交易账簿其他要素的头寸。
- 交易意图包括：短期转售、从实际或预期的短期价格变动中获利、锁定套利利润等。
- 金融机构须有明确的政策和程序界定交易账簿的纳入与排除。
- 可交易金融工具须无交易限制性条款，或可完全对冲；头寸须频繁且准确估值，组合须主动管理。
- 澳门金融管理局发行的、非用于交易目的的货币票据不应计入交易账簿。

### 2. 金融工具定义
- 金融工具指形成一方金融资产及另一方金融负债或权益工具的合约。
- 包括基础金融工具（现金工具）和衍生金融工具。

## 二、第一部分：利率风险（交易账簿）——债务证券及债务相关衍生工具的特定风险

### 1. 覆盖范围
- 交易账簿中按发行人类别报告债务证券及债务相关衍生工具的多头与空头头寸。
- 包括所有固定利率和浮动利率债务证券（如债券、浮动利率票据、存款证等）及类似工具，包括非可转换优先股。
- 可转换债券（可按约定价格转换为发行人普通股的债务发行或优先股），若其交易方式类似债务证券，则视为债务证券。
- 标的为债务证券的衍生合约（如债券期货或债券期权），或代表一篮子债务证券的指数，也应包括在内。

### 2. 分类与时间档
- 头寸须先按发行人分类（如OECD国家政府或央行、多边开发银行等）。
- 再按剩余期限归入相应时间档：
  - 6个月或以下
  - 6个月以上至24个月
  - 24个月以上
- 衍生合约按标的证券的发行人及剩余期限报告。

### 3. 投资级债务证券的认定
- 非政府、银行或公共部门实体发行的债务证券，若满足以下条件之一，可归类为投资级：
  - 被至少两家AMCM认可的评级机构评为投资级；
  - 被一家评级机构评为投资级，且未被任何其他AMCM认可的评级机构评为低于投资级。
- AMCM认可的评级机构及最低投资级评级：
  - Fitch Inc.：BBB-
  - Moody's Investors Service, Inc.：Baa3
  - Rating and Investment Information, Inc.：BBB-
  - Standard & Poor's Corporation：BBB-
- 拟使用其他评级机构评级的债务证券作为投资级的，须事先咨询AMCM。

### 4. 头寸报告与抵消规则
- 各类债务证券的多头与空头头寸须分行报告。
- 除完全相同工具（发行人、票息、货币、期限完全相同）的多空头寸外，不允许抵消。
- 特定风险资本要求 = 头寸 × 下表相应的特定风险资本因子。

### 5. 特定风险资本因子表

| 发行人类别 | 特定风险资本因子 |
|------------|------------------|
| 澳门特别行政区政府或AMCM发行的债务证券 | 0% |
| OECD国家中央政府或央行、香港特别行政区政府发行的债务证券 | 0% |
| 非OECD或香港以外国家的中央政府或央行发行、以发行人本国货币计价并融资的债务证券 | 0% |
| 上述以外的其他国家中央政府或央行 | 0.25%（剩余期限≤6个月）<br>1.00%（剩余期限>6个月且≤24个月）<br>1.6%（剩余期限>24个月） |
| 澳门特别行政区、OECD国家或香港特别行政区的公共部门实体 | 同上 |
| 多边开发银行 | 同上 |
| 在澳门、OECD国家或香港注册的银行 | 同上 |
| 在其他国家注册的银行 | 同上 |
| 被至少两家AMCM认可评级机构评为投资级的债务证券；或被一家评为投资级且未被其他机构评为低于投资级 | 同上 |
| 所有其他债务证券 | 8% |

## 三、第二部分：利率风险（交易账簿）——债务证券、债务相关衍生工具及利率相关衍生工具的一般市场风险

### 1. 覆盖范围
- 交易账簿中债务证券、债务相关衍生工具及利率衍生工具的多头与空头头寸，按期限位置报告。
- 包括第一部分所有工具，以及所有对利率变动敏感的利率衍生工具和表外工具，如：
  - 利率期货、远期利率协议（FRA）、其他远期合约
  - 利率互换和交叉货币互换
  - 利率期权
  - 远期外汇头寸
- 还包括交易账簿中因上述工具产生的任何利率风险。

### 2. 货币分表与期限阶梯
- 不同货币的头寸须使用单独表格报告。
- 头寸归入包含13个时间档的期限阶梯（低票息工具为15个时间档）。
- 固定利率工具按剩余期限分配；浮动利率工具按至下一个重定价日的期间分配。
- 衍生工具和表外项目视为多头与空头头寸的组合。

### 3. 衍生工具处理规则
- **期货和远期合约（含FRA）**：视为零息特定无风险证券的多头与空头组合。期限为至交割或行权日，加上（如适用）标的工具的存续期。
  - 示例：8月到期的三个月利率期货多头，在6月报表中视为5个月期零息无风险证券多头 + 2个月期零息无风险证券空头。
- **利率互换**：
  - 收取或支付浮动利率、支付或收取固定利率的互换，视为：
    - 浮动利率工具的多头或空头（期限至下一个利息确定日）；
    - 固定利率工具的空头或多头（期限至互换合约到期日）。
- **支付/收取固定或浮动利率对其它参考价格（如股价、商品价格）的互换**：利率端按至下一个利息确定日的剩余期限归入相应时间档；股票或商品端计入第三部分或第五部分。交叉货币互换的各端分别在相关货币的期限阶梯中报告。
- **远期外汇合约**：视为两种不同货币的零息特定无风险证券的多头与空头，期限与远期合约相同。
- **期权合约（标的为债务证券或利率）**：按Delta加权头寸，采用两端法报告——标的合约生效时一笔，到期时一笔。
  - 示例：债券期货的看涨期权，9月交割债券，在6月报表中视为债券多头 + 三个月存款空头，均按Delta加权。
  - 买入8月三个月利率期货看涨期权，在6月报表中按Delta等值视为5个月多头 + 2个月空头；卖出期权则相反。
  - 带上限或下限的浮动利率工具视为浮动利率证券与一系列欧式期权的组合。

### 4. 抵消规则
- 计算一般市场风险资本要求时，可排除期限阶梯中完全相同工具（发行人、票息、货币、期限相同）的多头与空头头寸。
- 可全额抵消期货合约或远期合约中的匹配头寸与标的敞口，但零息特定无风险证券的头寸须计入一般市场风险资本要求计算。
  - 示例：持有债券多头并在报告日通过期货或远期合约卖出该债券，债券多空可抵消，但须按债券公允价值报告一笔零息特定无风险证券多头，期限至期货或远期合约标的债券的交割日。
- 同一类型衍生合约（含期权Delta加权头寸）的反向头寸可视为匹配并全额抵消，条件包括：
  - 标的敞口相同、名义价值相同、计价货币相同；
  - 期货合约：相关标的利率敞口相同且到期日相差不超过7天；
  - 互换合约和FRA：利率相同且票息相差不超过15个基点。

### 5. 一般市场风险资本要求计算步骤
1. 对每个时间档的匹配头寸（风险加权多头与空头总额的较小绝对值）应用10%的市场风险资本因子，得出各匹配头寸的资本要求（“纵向豁免”）。
2. 进行两轮横向抵消，得出各区域（如0-1年、1-4年、4年以上）内及跨区域的匹配头寸资本要求（“横向豁免”），具体比例见下表。
3. 对抵消后剩余的净风险加权多头或空头头寸应用100%的市场风险资本因子。

### 6. 横向豁免比例表

| 区域 | 时间档 | 区域内 | 相邻区域间 | 区域1与3之间 |
|------|--------|--------|------------|--------------|
| 区域1 | 1个月或以下 | 40% | 40% | 100% |
| | >1至≤3个月 | | | |
| | >3至≤6个月 | | | |
| 区域2 | >6至≤12个月 | 30% | 40% | |
| | >1至≤2年 | | | |
| | >2至≤3年 | | | |
| | >3至≤4年 | | | |
| 区域3 | >4至≤5年 | 30% | 40% | |
| | >5至≤7年 | | | |
| | >7至≤10年 | | | |
| | >10至≤15年 | | | |
| | >15至≤20年 | | | |
| | 20年以上 | | | |

> 注：票息低于3%的项目，区域2覆盖>1年至≤3.6年，区域3覆盖>3.6年至20年以上。

### 7. 资本要求汇总
- 一般市场风险资本要求 = 所有时间档纵向豁免资本要求总和 + 各区域及跨区域横向豁免资本要求总和 + 剩余净风险加权头寸的资本要求。
- 各货币分别计算，按当前市场汇率折算为澳门币后汇总。

## 四、第三部分：股票敞口（交易账簿）

### 1. 覆盖范围
- 交易账簿中所有市场行为类似股票的金融工具的多头与空头头寸，但不包括非可转换优先股（归入第一、二部分）。
- 包括普通股、行为类似股票的可转换证券、买卖股票的承诺。
- 受股价变动影响的股票衍生工具和表外头寸，包括个股和股指的期货、互换和期权。

### 2. 衍生工具转换规则
- **个股期货和远期合约**：按当前市场价格报告。
- **股指期货**：按名义标的股票组合的市值报告。
- **股票互换**：视为两个名义头寸。
- **股票期权和股指期权**：按Delta加权头寸报告。

### 3. 报告要求
- 多头与空头头寸分行报告，按市场逐一报告。
- 须在单独栏目注明所报股票或股票相关衍生工具标的股票所在交易所的地点（如香港、纽约等）。
- 可在每个交易所对相同股票或股票指数的同交割月匹配头寸全额抵消，得出单一净多头或空头头寸；也可将某股票期货合约与同一股票的反向头寸抵消。
- 股票互换中涉及固定或浮动利率收付的利率敞口，以及股票期货或远期合约，适用第26(a)段的期限法。

### 4. 资本要求
- **特定风险**：总毛头寸（多头+空头）的8%。
- **一般市场风险**：总净头寸（多头总和与空头总和之差）的8%。
- 不同市场的净多头与空头不可抵消。

## 五、第四部分：外汇敞口

### 1. 覆盖范围
- 各外币（含黄金）的净敞口头寸。
- 净敞口 = 即期净头寸 + 远期净头寸 + 确定会调用且可能无法收回的担保（及类似工具）。

### 2. 报告要求
- 每种货币分三栏报告：
  - 不含期权合约的净敞口头寸；
  - 期权合约的净多头或空头头寸；
  - 含期权合约的净敞口头寸。
- 远期货币和黄金头寸按当前即期市场汇率估值；以净现值为管理会计基础的可使用净现值（按当前利率贴现、按即期汇率估值）。

### 3. 资本要求
- 外汇（含黄金）市场风险资本要求 = 8% × [（净多头或空头头寸总和 − 澳门币对港币和/或美元头寸）+ 黄金净头寸]。
- 澳门币头寸作为平衡项报告，使所有货币净多头总和等于净空头总和。
- 澳门币、港币、美元均为多头或均为空头时，该头寸报零；三者净多头总和等于净空头总和时，报净多头总和；否则报净多头总和与净空头总和的较小者。

## 六、第五部分：商品敞口

### 1. 覆盖范围
- 商品持仓及所有受商品价格变动影响的商品衍生工具和表外头寸。
- 商品指可在二级市场交易的有形产品，如农产品、矿物（含石油）和贵金属。
- 黄金按第四部分作为外汇处理，不在此作为贵金属处理。

### 2. 报告要求
- 按铂金、白银、其他贵金属、其他产品等报告多头或空头头寸，并注明第3-5项所含商品名称。
- 每种商品头寸（即期+远期）先以标准计量单位表示，再按当前即期汇率折算为澳门币。
- 商品衍生工具转换为名义商品头寸：
  - 个股商品期货和远期合约：按桶、公斤等名义金额计入；
  - 个股商品期权：按Delta加权头寸报告；
  - 商品互换（一端固定价格、一端当前市场价格）：按合约名义金额报告；支付固定收取浮动的为多头，收取固定支付浮动的为空头；若一端涉及固定或浮动利率收付，该敞口在第二部分报告；
  - 不同商品间的互换：归入相关商品项目；另一端产生的利率敞口按第26(a)段期限法在第二部分报告。

### 3. 资本要求
- 商品（含贵金属）持仓风险资本要求 = 每种商品净头寸（多头或空头）的15% + 每种商品总头寸（多头+空头）的3%（覆盖基差风险、利率风险和远期缺口风险）。

---

## 七、第六部分：加权市场风险敞口

- 从第一至第五部分提取各风险类别的市场风险资本要求总额。
- 市场风险资本要求总和 × 12.5 = 加权市场风险敞口。

## 八、附录：报告处理示例（摘要）

### 示例（1）固定利率债券
- 10年期美国国债多头，票息4.25%，面值100万美元，剩余期限7年，市价97.45。
- 澳门币等值市值7,815,490。
- 报告处理：
  - 第一部分：第1项，(d)栏，多头，MOP7,815K；
  - 第二部分美元表：“5至7年”时间档，(a)栏，多头，MOP7,815K。

### 示例（2）公司固定利率债券
- 10年期公司债券多头，标普及另一机构评为投资级，票息4.875%，面值1000万美元，剩余期限5年，市价100.22。
- 澳门币等值市值80,376,440。
- 报告处理：
  - 第一部分：第8项，(c)栏，多头，MOP80,376K；
  - 第二部分美元表：“4至5年”时间档，(a)栏，多头，MOP80,376K。

### 示例（3）浮动利率票据
- 美国公司发行的无评级浮动利率票据多头，票息5.75%，面值100万美元，6个月后重定价，市价101.492。
- 澳门币等值市值8,139,658。
- 报告处理：
  - 第一部分：第9项，(d)栏，多头，MOP8,140K；
  - 第二部分美元表：“3至6个月”时间档，(a)栏，多头，MOP8,140K。

### 示例（4）债券期货
- 10份5年期美国国债期货多头，面值每份10万美元，3个月后交割，可交割券为票息4.50%、5年期美国国债，当前价格98.29，转换因子0.9423。
- 报告处理：
  - 第一部分：第1项，(d)栏，标的工具市值，多头；
  - 第二部分美元表：“4至5年”时间档，(a)栏，多头；
  - 第二部分美元表：“3至6个月”时间档，(a)栏，空头。
- 标的工具市值 = (100,000 × 10 × 98.29% / 0.9423) × 8.02 = MOP8,366K。

### 示例（5）利率互换
- 单货币利率互换：收取年浮动利率，支付固定利率3.95%，面值2000万港币，剩余期限2.5年，当前浮动利率3.8%，6个月内重定价。
- 报告处理：
  - 第二部分港币表：浮动端为6个月浮动利率工具，“3至6个月”时间档，(b)栏，多头；
  - 第二部分港币表：固定端为2.5年固定利率工具，“2至3年”时间档，(b)栏，空头。
- 浮动端现值 = HKD20,382,916 ≈ MOP20,994K；
- 固定端现值 = HKD20,434,666 ≈ MOP21,048K。

### 示例（6）利率期货
- 10份3个月HIBOR利率期货多头，面值每份100万港币，6个月内交割。
- 报告处理：
  - 第二部分港币表：“6至12个月”时间档，(b)栏，9个月零息证券多头；
  - 第二部分港币表：“3至6个月”时间档，(b)栏，6个月零息证券空头。
- 9个月零息证券现值 = HKD9,728,000 ≈ MOP10,020K；
- 6个月零息证券现值 = HKD9,818,000 ≈ MOP10,113K。

### 示例（7）远期利率协议（FRA）
- 3对6 FRA卖出，标的3个月HIBOR，名义金额1000万港币，3个月内结算。
- 报告处理：
