# 风险暴露权重决策

这个程序按《商业银行资本管理办法》权重法，判定每一行属于哪一类风险暴露、适用哪个权重，再把结果写回工作簿。划分时用到的取值和命中规则另存留痕，便于以后倒查。

分类和权重以 `knowledge/权重法风险暴露分类.json` 为准。

## 准备

需要 Python 3.10 及以上。

```bash
python3 -m pip install -r requirements.txt
```

识别表结构、对应字段，以及规则停住后在允许档次里补条件，会调用通义千问。把密钥写在本目录的 `.env`：

```text
DASHSCOPE_API_KEY=你的密钥
```

## 运行

在本目录执行。整表计算按 `rwa_agent/pipeline.py` 里的 `STEPS` 顺序进行，当前第一步是分类和权重：

```bash
python -m rwa_agent.pipeline 你的工作簿.xlsx
```

只重跑这一步时：

```bash
python -m rwa_agent.paper_calc 你的工作簿.xlsx
```

第二个参数可以指定结果文件的路径。不写则生成 `你的工作簿_风险暴露分类.xlsx`。

## 结果

- Excel：第一张表是「风险暴露分类」，一行一笔，列出风险暴露类型、权重和判定说明。明细表末尾也写上这三列。另有一张「计算留痕」表，一行对应计算中的一步。敞口和风险加权资产写在留痕里，不写回明细列。
- `data/traces/工作簿名-计算留痕.json`：同一份步骤，每一行带有计算公式和代入结果。
- `data/traces/工作簿名-计算留痕.md`：按「取值、命中的规则、公式」写成的说明，可直接交给模型阅读这一次计算经历了什么。

阶段依次是取值、分类、权重、敞口、风险加权资产。用规则名可以回到 `权重法风险暴露分类.json` 对上那一条。

金额沿用底稿口径。敞口取账面余额一类的金额列。只有外汇名义本金、没有信用等值金额的表不计入。
